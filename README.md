# Service Metadata Schema

This repository contains the SWIM Service Description Schemas:

- Service Description Schema for SWIM Services Descriptions can be found in the description folder:
  - Reference [Description Folder](./description/)
- Service Description Schema for SWIM Services Definition can be found in the definition folder:
  - Reference [Definition Folder](./definition/)

Both schemas use types defined in the common folder:
- Reference [Common Folder](./common/)

Latest version of the schemas is v3.0.
Version 2.0 schemas are also provided in the Description and Definition folders for reference.
